# PetAssist

## Область работы

- Целевая версия игры для новых задач и публикаций — WoW Forever (Camelot). Начинай с `PetAssist_Camelot.toc`, `Forever/Compat.lua` и общей логики в `PetAssist.lua`.
- Classic Era — прежняя версия. Сохраняй существующий код и файлы для неё. Отдельные доработки и публикации для Classic Era делай по прямому запросу пользователя. При изменении общей логики запускай существующие регрессии для обеих версий.
- Публикуй новые сборки через GitHub Actions. Процесс `.github/workflows/release.yml` собирает, проверяет и загружает пакет Forever.

## Работа и проверка

- Пользователь сам управляет WoW и проверяет сборки в игре. Для диагностики используй код, файлы клиента, автотесты и результаты ручной проверки пользователя. Давай короткие шаги для воспроизведения и указывай, что именно нужно проверить на экране.
- Защищённые действия питомца привязывай к нажатию игрока. Проверяй команды, условия и доступные действия по исходникам целевой сборки Forever. Если позиция команды на панели питомца может измениться, перепроверяй её перед использованием. При невозможности проверки пропускай этот способ.
- Перед публикацией прогони `python3 tests/run.py`, проверь собранный ZIP и обнови `CHANGELOG.md`. Автотесты проверяют сформированные команды и передачу действия игрока, а фактическое переключение стойки в клиенте подтверждает ручная проверка.

## Публикация

- Когда пользователь просит выпустить сборку, сам выбирай канал по риску изменения и результатам проверок. В итоговом сообщении указывай канал, версию и результаты проверки.
- **Alpha** (`v1.9.3-alpha.1`) — экспериментальные изменения, включая новые защищённые действия и обходы несовместимости, пока ключевой сценарий ещё не подтверждён в игре.
- **Beta** (`v1.9.3-beta.1`) — основной сценарий проверен вручную на целевой сборке Forever, ещё нужны проверки дополнительных случаев или обратная связь.
- **Release** (`v1.9.3`) — автотесты и относящиеся к изменению игровые проверки на Forever прошли. Для изменений панели действий и макросов проверь выполнение оригинального действия, в том числе в бою. Актуализируй чек-лист `tests/IN_GAME.md` для целевой версии.
- Поднимай патч-версию для исправлений и минорную для заметных дополнений. Для итераций предварительной версии увеличивай номер после `alpha.` или `beta.`. Переход на 2.0 согласуй отдельно.
- После запуска дождись окончания GitHub Actions и проверь, что CurseForge принял пакет Forever в выбранном канале. Сообщай отдельно об успешной загрузке и о результатах проверки в игре.
